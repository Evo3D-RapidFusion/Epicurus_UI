Troubleshooting Steps:

  1. Check that your local web server is running
  2. Ensure all files are in the correct locations
  3. Verify file permissions
  4. Check that required dependencies are available locally

⚠️ Important Note

When operating in offline mode:

  • G-code commands will be simulated and not sent to actual hardware
  • Temperature and other data will be mock values for display purposes
  • Changes to settings won't be saved permanently

Tips for Offline Use:

  • Use direct file paths rather than URLs with 'localhost'
  • Include fallback mechanisms for all external resources
  • If using Apache, ensure mod_rewrite is enabled
  • Check browser console for specific error messages (F12)
